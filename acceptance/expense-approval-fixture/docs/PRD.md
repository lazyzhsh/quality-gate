# 报销申请审批 PRD

版本 0.1.0；负责人：财务产品组；状态：验收基线。

## 问题与用户

员工需要提交费用申请，审批人需要防止自批和跨租户审批，财务需要在报销完成时看到借贷平衡的流水。现有手工表格难以追踪申请状态与重复操作。

## 范围

本轮提供本地服务模块，无网页和外部付款接口。金额统一为整数分，仅支持 CNY。一个申请按 `submitted → approved → reimbursed` 单向前进。每个状态变化保存到项目指定的存储目录。审批限额为 100000 分；超过限额拒绝。申请人不得审批自己的申请；跨租户用户不得查询或审批。

## 验收标准

- AC-01 正常：员工提交 12000 分申请；同租户另一位审批人批准后，财务报销，状态变为 reimbursed，账本借贷各 12000 分。
- AC-02 边界：100000 分可审批；100001 分不可审批。
- AC-03 反例：0、负数、非整数金额拒绝且不写入申请。
- AC-04 异常：跨租户读取与审批、自批均拒绝；既有状态不改变。
- AC-05 状态转换：重复审批、未审批先报销均拒绝；一次报销只产生一组平衡分录。

## 非功能与交付

本地流程不依赖网络或第三方包；关键业务源码不得使用 `eval`；每条对外 API 契约必须显式声明鉴权；下游调用预算不超过上游预算。发布必须有运行、回滚和配置说明以及同次回滚演练。
