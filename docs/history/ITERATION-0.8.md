# v0.8：L5 交付与运行就绪 Gate

`readiness` Gate 校验发布清单中的必需角色制品存在、非空且在项目根内，并记录每个文件的 SHA256；同时要求配置的验证 Gate 在同一次运行中 PASS。制品缺失/空文件或演练失败为 FAIL；无效清单、越界路径、未知验证 Gate 为 ERROR。可用于把运行手册、回滚说明、配置样例、迁移步骤和演练脚本关联成一条交付证据链。

`examples/delivery-demo` 提供隔离的回滚演练。它只检查示例数据恢复，不代表生产迁移已经执行或实际环境可回滚。正式项目应把 `verificationGateIds` 指向真实的迁移/回滚、部署烟测和运行检查，并按需扩展 `requiredRoles`。

先运行正反例测试和旧 Gate 回归，再进行全链路组合；客户端实机验收最后统一执行。
