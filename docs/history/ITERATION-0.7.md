# v0.7：L4 可量化工程策略 Gate

`metrics` Gate 由项目配置的 runner 产生架构、安全、性能等数值观察，内核用本次 runId 绑定结果，逐指标判断 `min`/`max` 阈值。缺失指标、非数值、旧结果、执行错误或超时为 ERROR；越界为 FAIL。可配合项目现有架构检查器、安全扫描器和基准测试工具，不在内核中硬编码特定语言工具。

`examples/metrics-demo` 仅演示：扫描示例模块中的禁用依赖与 `eval` 字样，并测量小函数执行时间。它是演示检查器，不构成完整安全扫描或可靠的生产性能基准。生产项目需替换 runner，并说明抽样、环境、误报与阈值依据。

正反例和协议错误测试先通过，再执行全量旧功能回归；客户端验收在六域完成后统一进行。
