# v0.5：本体关联的样例约束 Gate

L2 `semantic-profile` Gate 检查样例记录是否符合项目显式声明的形状约束，并确认形状所指类存在于可替换的 ontology provider。形状支持字段出现次数、值类型和可选枚举。FAIL 证据定位到记录 ID、字段及违例规则；形状无效、目标类不存在或 provider 不可用时 ERROR。

这是一套有界 JSON 约束原型，**不是 SHACL 实现**。FIBO provider 只提供概念身份与固定来源；字段约束由项目作者声明，不从 FIBO 自动推断。通过不证明本体全局一致、业务映射正确或持久化数据正确。后续可增加真正 SHACL 执行器并保留同一 Gate/Provider 分层。

验收：先写并运行正例、缺字段/错类型、未知概念和错误形状测试；与既有 Gate 全量回归。客户端升级仍留到六域开发完成后统一执行。
