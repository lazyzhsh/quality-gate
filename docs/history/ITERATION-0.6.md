# v0.6：L3 业务行为用例 Gate

`behavior` Gate 将一组明确的输入/期望输出发给项目配置的 runner。runner 必须执行被测业务代码，并返回与本次随机 runId 绑定的逐用例实际输出；内核做类型敏感的深度比较。缺失/额外用例、旧 runId、非 JSON、非零退出或超时都为 ERROR；业务结果不符为 FAIL。

示例 `examples/behavior-demo` 覆盖正常金额、边界零金额和不支持币种。它只证明被配置的案例及其可观察输出，不自动生成所有业务规则，也不证明持久化或外部依赖状态。runner 属于项目受信任代码，需审查其调用路径。

先以正反例测试协议和判定，再跑全量回归；客户端验收在六域完成后统一执行。
