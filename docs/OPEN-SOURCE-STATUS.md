# 开源状态与支持范围

1.24.0 是首次 GitHub 公开发行，仓库为 `lazyzhsh/quality-gate`，自有内容采用 MIT。它是可运行的早期工具，有明确子集与外部工具协议边界；不以开源发布代替生产认证或 v2.0 需求终审。

## 已调整的发布前问题

2026-10-01 全项目审查发现的 11 组问题已纳入本版本修复：输入删除/修改/过期后的旧结论复用、OWL 推理方向、账本整数精度、根目录符号扫描、SHACL 单边约束、Stop 预算、内置模块识别、SHACL 引擎组件与 Unicode、reasoner 事实交付、配置数组及 deferred ADR。正反例在 `tests/release-correctness.test.mjs`、freshness 和 adapter 测试中；具体规则见 [发布说明](release/RELEASE-1.24.0.md)。

## 证明边界与已知差距

- 原生、协议、部分是实现形态，不是完成率；RTM 仍保留 7 条部分需求。
- API/Schema 适配目前证明声明的子集；完整 OpenAPI、数据库方言和真实 ORM 项目覆盖仍需完善。
- 浏览器截图参考 runner 已存在；成熟视觉差分、固定渲染环境和基线治理仍需使用项目补齐。
- AC 与真实测试用例的独立绑定、生产依赖图/专业扫描器、真实进程或依赖故障的恢复证据仍需完善。
- 整体 PASS 不等于每条 Claim 都已证明；条件未命中或有意裁剪的检查应结合逐门禁 SKIP 解释。
- 证据力汇总中“核验级”表示存在核验信号，可能同时包含自报观察；原始记录增加可复核性，不证明 runner 诚实。
- 文件快照检测内容、新增、删除和重命名；不证明仓库外或网络状态。外部 runner、Git/运行时检查及时间政策不复用旧判定。生成输出使输入快照不稳定时，后续 Stop 会重新执行。
- SHACL 是 JSON 子集；对象、语言标签、枚举和正则到 RDF 的映射可能存在标准模型差异。可选引擎采用并集判定，差异不得静默转为 PASS。OWL 不是完整开放世界 reasoner。
- 1.24.0 的新修复验证属于源码 CLI/Hook 模拟与本机 Windows；本轮没有新增 ZCode 实机、最低 Node 版本或跨平台认证。以前的实机记录只证明当时版本。

## 公开快照与历史资料

公开仓库从经过发布检查的初始快照开始，本机 Git 开发历史保留。`evidence/` 和 `dist/` 为本机过程产物，不进入公开源码或新交付包；历史文档保留当时叙述，里面引用的旧证据/安装包路径可能只在维护者本机存在，不应解释成新版本的公开验证依据。新版本验收摘要记在发行说明中，复现代码随源码发布。

开发者从源码运行 README 中的命令即可独立产生自己的证据。发布包从同一源码构建、解包验证，GitHub Release 提供新版本 zip 与 SHA256。维护者不承诺旧版本支持或固定修复时限。

## 后续完善顺序

1. 用真实业务项目衡量错误放行、错误阻断、接入成本、耗时与修复轮数。
2. 完成逐 Claim 的证明范围显示、混合证据来源显示和 AC→真实用例绑定。
3. 按 RTM 的 7 条部分需求逐项补支持面与验收证据，再审议 v2.0。
4. 第二宿主与新增功能在效果验证后评估；仓库自有 CI、签名与已裁剪功能不因开源发布自动恢复。
