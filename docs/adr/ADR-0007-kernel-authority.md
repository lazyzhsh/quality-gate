# ADR-0007：防伪造判定收归内核（审计链重算、基线判定）

- 状态：已接受（v1.5 工作包 C 定案）
- 日期：2026-09-25

## 背景

"证据独立性"（原始设计 §4.5）要求证据不能由被验证方自行炮制。两类具体威胁：runner 谎报审计日志哈希链完整性；runner 自判 F2P/P2P 基线结果（把"基线通过"说成"基线失败"以伪造新行为）。

## 决策

凡属"可用纯算术复核的声明"，判定必须收归内核：

1. **审计链**：consistency 门禁的 sha256(prev:seq:actor:action) 链由**内核重算**，runner 只提交原始事件序列；链头哈希入证据。
2. **F2P/P2P 基线**：behavior 门禁的期望与基线判定由内核执行——runner 只报告实际值与基线实际值，"新行为在基线上是否失败"由内核比较得出。
3. 同类还有 budget 的预算守恒算术、零和账本聚合谓词（sum(entries)==0）。

## 后果

- 正面：runner 造假面收窄到"原始观察值"层（其可信度由 Evidence 的工具来源/ provenance 字段与多源对账继续治理）。
- 负面：内核复杂度上升（每类判定都要协议化）；runner 协议更严格。

## 备选方案

信任 runner 结构化结论（拒绝：自证问题）；外部公证服务（拒绝：引入联网与信任设施，超出离线约束）。
