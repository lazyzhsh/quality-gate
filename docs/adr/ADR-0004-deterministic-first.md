# ADR-0004：确定性优先，LLM Second

- 状态：已接受（v0.1 §4.2/§4.3 原则）
- 日期：2026-09-23

## 背景

Agent（LLM）有动机宣称"已完成/已通过"；若判定依赖 LLM 自述，证明链退化为自我声明。用户明确要求"LLM 说没问题"不得作为最终 PASS 证据。

## 决策

所有 Gate 判定 = **运行真实工具 + 比较结构化结果 + 落证据**，全程确定性（固定 seed 的性质测试亦然）。LLM 的合法角色限定为：提取需求/假设候选、解释失败摘要、生成配置提案（ontology proposals 仅登记不生效，pin 需人工确认）。框架自身异常一律 ERROR（fail-closed），绝不因框架错误放行。

## 后果

- 正面：同输入同判定，可回归、可审计；v1.5 的"审计链/预算/F2P-P2P 判定收内核"（ADR-0007/0008）是本原则的延伸。
- 负面：需要为每类检查定义结构化协议（runner 协议成本）；无法自动覆盖未结构化的主观判断。

## 备选方案

LLM-as-judge（拒绝：不可复现且可被诱导）；纯静态配置校验不做执行（拒绝：无法发现真实失败）。
