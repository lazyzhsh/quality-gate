# ADR-0016：统一语言治理（GLOSSARY 唯一登记处与术语纪律）

- 状态：已接受（用户 2026-09-30 四问选型 D+A+A+B——作用域全量含协议键、自造词全部规范化、双轨映射制、v1.15.0 实机验收并入 v1.16.0；T2 六项裁决同日完成，其中快赢→小迭代为用户指定、推荐案"小步补丁"未采用）
- 日期：2026-09-30

## 背景

迭代累积出系统性概念混乱（2026-09-30 三轮盘点：文档/代码/约束三面）：15 活文档+15 ADR 无任何术语表；基线 6 义、重放 2 义（重算义占用安全词"防重放"）、附加门禁族 5 变体（附加门禁/附加库/附加项/add-on/ADDONS）、锚族 4 义（锚点/验证锚/示例锚/动词锚定）、L0–L5 双命名方案并行（PRD 短名 vs CONFIG-GUIDE 长名）、验证动词 6 词无分工（核验/验证/校验/核对/交叉核验/审计）、约 30 个非惯用自造词（收口 47 处/锚点 47/降权 48/转录 46/对拍/超面/残差/敞口…）、ID 前缀撞名（C1/R1 双义）；代码侧 `domain` 字段实为 L0–L5 层级、init answers `addOns` 与 update changes `addAddOns` 拼法不对称。没有权威登记处，混用不可逆地累积。

## 决策

1. **GLOSSARY 为概念唯一登记处**（`docs/GLOSSARY.md`，活文档）：规范中文/代码名/定义/限界上下文/弃用别名；新概念先入表再进文档与代码（AGENTS 约定同步）。
2. **限界上下文六分**：内核产品域/宿主适配/参考工具适配器/演示/过程管理/历史档案；一概念一上下文一名，跨上下文同名必须同义或加限定词。
3. **双轨映射制**：中文文档用规范中文、代码与协议保持英文，GLOSSARY 持双向映射与借词清单（runner/kind/PASS 等）。
4. **替换判定三问**：软件/项目管理惯用词可用；描述性复合词可用；比喻/类比/跨领域借词改惯用语——据此全部替换约 30 个自造词（弃用词清单=GLOSSARY §6），保留词逐项附理由（§6.1）。**修订（2026-09-30 发布当日，用户裁决）**：白名单、台账、灰度、口径、敞口 五词改判保留（从 §6 移出、回滚其替换）；§5 ID 前缀注册表按层次与目标分组规范——详见 GLOSSARY §7-7。
5. **概念拆义**：基线/基准二分（F2P/P2P 对照实现 vs 变更参照）；L0–L5 长名规范+短名叙述简称；ID 前缀注册表（样例 id 让位 CL-n/RS-n）；快照/live/命令多义加限定词消歧。
6. **协议键随批迁移**（作用域 D）：`domain→level` 族（gates[].level/requiredLevels/levelCoverage/evidence[].level）、`addAddOns→addOns`、配置与 run 报告 schemaVersion 0.1→0.2；旧键 fail-closed+迁移表（v1.8/v1.9 先例）；归档 run 渲染读兼容垫片（level=level??domain）。观察协议与 transcript schema 键零改名。
7. **历史档案不回写**：docs/history、docs/release、evidence/、ADR-0001–0015 正文旧词=历史称谓；活文档历史性小节中的版本主题名按专名保留（如 v1.15 主线"baseline 内容内核重放"），其余 generic 术语词级清扫。
8. **防回归**：`tests/glossary.test.mjs` 按弃用词清单在活文档集强制零出现（主题专名白名单、"防重放"条件例外），GLOSSARY 结构与 L0–L5 名称一致性同测。

## 后果

- 正面：概念有唯一登记处与机械防回归；文档/代码/测试/演示统一表达；协议键名与语义一致（level）；弃用词不可静默回流。
- 负面/边界：lint 只拦字面弃用词，拦不住语义漂移与新同义词（靠 GLOSSARY 纪律与评审）；旧 run 档案渲染依赖读兼容垫片（只覆盖本轮键差异，不承诺未来 schema 前向兼容）；协议键迁移是破坏性配置变更（仓内 37 demo+根配置+夹具同批迁移，RELEASE-1.16.0 附迁移表）；客户端缓存旧版文案存在一版差（更新后消除）。

## 备选方案

仅文档层统一（拒绝：文档-代码语言继续分裂）；协议键定义固定不迁移（拒绝：用户选 D 彻底统一，且盘点后迁移面全在仓内、单一消费者）；自造词保留少数已定义领域词（拒绝：用户选 A 全部规范化）；历史性小节整体豁免不清扫（拒绝：generic 词级替换可保持 lint 全文件扫描简单可靠，主题专名单独白名单即可）。
