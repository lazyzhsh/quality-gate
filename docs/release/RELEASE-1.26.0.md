# RELEASE-1.26.0（2026-10-06，受控表达第二批——报告表达）

## 主线：RTM X13（应用方案 §9 批次 2）

逐检查来源、逐 Claim 范围、advisory 可见性、旧报告与复用说明。**stdout JSON、退出码、归档协议与判定语义零变化**——全部改动位于渲染层（summary/adapter stderr、Markdown、提示指令）与测试；未新增结构化字段（逐 Claim 复用报告中已有的 `claims` 与 `evidence[].claimId`，advisory 计数复用内核已有的 `details.advisoryHits`/`rules`）。

## 变更清单

1. **逐门禁来源细分**（`lib/summary.mjs`）：全表新增**来源列**——PASS 门禁显示 `核验（信号标签）`（git 基线/基线内容/原始输出解析/双次运行一致/持久化快照/来源指纹）、`声明`（定量自报、无内核可独立核验的证据信号）、`降级（标签）`（内嵌基线/静态观察/declared 使用面/declared 来源/域不可核验）及其并存组合；无信号与非 PASS 显示 `—`。证据力聚合行追加**来源分布**（`来源 核验 N、声明 M、降级 K`，优先级同聚合等级：降级＞核验＞声明）。**混合来源不再可能被读成全部已核验**——一个强信号只为其所在门禁背书。
2. **advisory 可见性**：brief 与全表均新增 `advisory 建议命中` 行（总计数＋规则×命中数清单＋"不阻断判定"限定）；无命中不显示（不虚报）。此前 advisory 命中只入证据、摘要层完全过滤——"检查已接入但用户看不到"。
3. **例外不隐藏**：brief（PASS）新增例外行——已豁免例外（WAIVED 及期限，"不改变门禁判定，仅免于登记阻断"）与未决例外（登记即阻断）；此前仅全表呈现。
4. **声明关联（逐 Claim 范围）**：全表新增 `声明关联` 行——逐 claimId 列出关联门禁与结论，无关联门禁执行的声明标 `未验证`；brief 新增 `未验证声明` 行。边界句固定随行："门禁 PASS 证明其配置输入与观察，不等于声明全文已被证明"。旧归档兼容：条目无 `claimId` 时不呈现（不误报未关联）。
5. **Stop 边界表达**（`hooks/adapter.mjs`）：new-only 放行消息明示"**本次报告仍为 FAIL**"；复用归档的阻断标记携带**原运行时间与运行标识**（`复用归档 run <id8>·原运行 <finishedAt>，未重跑门禁`）；adapter 外层异常消息明示"宿主本次未阻断；该消息不构成质量判定"并给出取得 CLI 判定的完整命令。SessionStart 提示提及来源列。
6. **提示指令**（SKILL 第 5/8 项）：来源列诚实读法（混合来源≠全部核验）、advisory 必须呈现不得静默、声明关联读法与"关联通过≠声明已证明"。

## 验证（§9 批次 2 验收条件逐项）

- **混合来源不能显示为全部已核验**：新用例构造同运行内 核验/声明/降级 三类门禁——断言各门禁来源列如实、仅声明来源的门禁不得含"核验"、分布行计数正确。
- **FAIL/ERROR/SKIP 不被展示成 PASS**：非 PASS 门禁来源列为 `—`（ERROR 用例断言）；advisory 用例断言业务判定保持 PASS；brief 例外用例断言 waived-only 不显示未决例外。
- **归档读取兼容**：旧形状（条目无 claimId）不呈现声明关联、不误报未验证；`qgate report` 重渲染归档守卫行不变（既有用例）。
- **复用说明**：configuration 门禁 FAIL 归档二次 Stop 断言复用标记含原运行时间与未重跑说明（复用面仍限纯文件式确定性 kind——command 恒重跑，边界不变）。
- 全量回归 622 项全过 0 SKIP（616＋新增 6：summary×4 混合来源/advisory/brief 例外/声明关联，adapter×2 外层异常指引/FAIL 复用标记）；受影响 demo 与打包解包复验见"版本与证据"。

## 边界与注记

- 来源列与分布是**实测信号的展示**，不是新采集协议：无信号的 PASS 门禁显示 `—`，不代表低风险或高可信（W11）。
- 声明关联只计算确定性事实（关联数与结论）；"声明已被证明"不能靠关联关系推断——边界句固定随行。
- Stop PASS 静默仍是客户端平台行为（v1.7.4 记录）；可见性由提示层承载。
- 客户端更新到 1.26.0 后新消息文案生效；1.24.0–1.26.0 实机验收可同轮收尾。
